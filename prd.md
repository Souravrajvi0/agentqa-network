# Product requirements (summary)

Full narrative requirements are captured in the hackathon brief. This project implements:

1. Multi-user RBAC and project membership
2. Test case + cycle management with execution history per build
3. Atomic test claiming with conflict errors
4. Priority recommendations with stored reasons
5. Developer-triggered testing changes with QA lead approval
6. Design decision registry linked to tests
7. Knowledge entries linked to tests/modules
8. Defect lifecycle states
9. Real-time dashboard updates
10. Playwright automation via approved command map
11. Switch collaboration via MCP tools + optional bridge messaging

Human approval remains required for release readiness and priority overrides.
