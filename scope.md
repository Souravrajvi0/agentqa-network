# Scope

AgentQA Network targets coordinated software testing across humans and independently owned AI agents connected through Switch rooms.

In scope:

- Shared test inventory, assignments, executions, and release context
- Duplicate-prevention and explainable prioritization
- Design decision and developer change workflows
- Defect tracking and cross-QA knowledge
- Agent-facing tools (REST + MCP) and Switch notification bridge

Out of scope for this repository:

- Hosting Switch server itself (use Switch Console / team deployment)
- Replacing Mattermost/Slack chat UI (link and notify via Switch)
